# YMM4からAviUtl2へ、exo出力のように字幕と音声を連携！

YMM4で作成した会話素材を会話フォルダとして書き出し、AviUtl2のタイムラインに字幕と音声を配置するプラグインです。exoファイル自体は生成せず、dialogue.settingを介して連携します。

## 編集スタイル

**YMM4の字幕設定は厳密にエクスポートしません。** 会話本文・音声・タイミングをAviUtl2へ渡し、字幕の見た目や装飾はAviUtl2側でアレンジして仕上げる編集スタイルを前提にしています。フォントサイズや色など一部の基本値は反映しますが、YMM4上の字幕表示を完全再現する機能ではありません。

## 使い方

1. YMM4の「Dialogue出力」から会話フォルダを書き出します。
2. AviUtl2の「ファイル > インポート > Dialogue Timeline読み込み...」を選び、出力フォルダを指定します。
3. 字幕と音声オブジェクトが配置されたら、字幕の細かなデザインや位置をAviUtl2で調整します。

会話フォルダにはdialogue.setting、text、audioが入り、テキストと音声はインデックスで対応します。
